#### 1. Создайте скрипт который создаёт папку заполняет её файлами ( имена 1-4 ) и записывает в них информацию о текущей дате, версии ядра, имени компьютера и списке всех файлов в домашнем каталоге пользователя от которого выполняется скрипт( не забудьте сделать проверку на существование файлов и папок)

И выполняем условие **7 задания**: скрипт работает так, что он выполняется в домашней папке того, кто его вызывает.
Cоздадим скрипт в `/usr/local/bin/`:
```

#!/bin/bash


cd "$HOME" || exit 1 //переход в домашний каталог ЛЮБОГО пользователя, кто его вызывает, если это невозможно, выходим с ошибкой
TARGET_DIR="$HOME/test_folder" // переменная для хранения пути пользователя

if  ! -d "$TARGET_DIR" ; then // проверка на существование папки
    mkdir -p "$TARGET_DIR"
fi

for i in 1 2 3 4; do //проход по циклу
    FILE="TARGET_DIR/i" //переменная для пути файла
    if  ! -f "$FILE" ; then //проверка на существование файла
        touch "$FILE"
    fi //конец блока if

    {
        echo "Дата: $(date)"
        echo "Версия ядра: $(uname -r)"
        echo "Имя компьютера: $(hostname)"
        echo "Файлы в домашней папке $HOME:"
        ls -a "$HOME"
    } > "$FILE" // перезапись в файл
done //конец for

```

#### 2. Создайте юнит который будет вызывать этот скрипт при запуске. Проверьте
Откроем unit-файл и настроим его: `Type=oneshot` — скрипт запускается один раз и завершается,`ExecStart` — путь к твоему скрипту (`/usr/local/bin/script.sh`), `User=` — от какого пользователя запускать, `WantedBy=multi-user.target` — запуск при старте системы:
![[Pasted image 20251114142020.png]]

Далее обновляем конфигурацию (`daemon-reload`), включаем юнит в автозагрузку (`enable script.service`) и запускаем юнит прямо сейчас (`start script.service`). И в конце проверяем работу при помощи (`status script.service`):
