#### 1. Что такое ssh ключи и зачем они нужны?
SSH-ключи - это пара криптографических ключей, используемых для безопасного подключения к удалённым серверам по протоколу SSH (Secure Shell) без ввода пароля. SSH-ключи состоят из приватного ключа и публичного. SSH-ключи нужны для безопасного и удобного доступа к удалённым серверам без ввода пароля.

---
#### 2. Как их создать?
При помощи команды: `ssh-keygen -t ed25519`, она генерирует и приватный, и публичный ключ, используя при этом алгоритм `ed25519`.

---
#### 3. Создайт пару публичный/приватный ключ ed_25519, где они хранятся?
Используя команду из прошлого пункта создаем `ssh-ключи`, я решила не устанавливать пароль, поэтому просто прожала пару раз `enter`.

![Создание SSH ключей](images/Pasted%20image%2020251224181643.png)

По умолчанию ключи сохраняются в скрытой папке `.ssh` домашней директории пользователя:  `~/.ssh/id_ed25519` (приватный),  `~/.ssh/id_ed25519.pub` (публичный).

---
#### 4. Скопируйте публичный ключ на ваш сервер, в каком файле он будет храниться?
Перекинем публичный ключ на мой сервер, это можно сделать быстро при помощи команды `ssh-copy-id`. При использовании этой команды ключ будет сохранен на сервер в файл `/home/user/.ssh/authorized_keys`.

---
#### 5. Попробуйте подключиться к серверу, у вас запросили пароль?
О чудо, нет! Наконец-то не надо копировать тот страшный большой пароль. Следовательно, ключ скопирован успешно.

![Подключение без пароля](images/Pasted%20image%2020251224182713.png)

---
#### 6. Запретите подключение с паролем для всех пользователей, оставьте только с помощью ключа.
Через `vi` открываем файл конфигурации и меняем строчку `PasswordAuthentication` на `no`, и на всякий добавляем `PubkeyAuthentication yes`, чтоб разрешить входить по ssh (хотя оно и так по умолчанию должно быть на yes, не хотела рисковать потерей доступа к серверу..)
