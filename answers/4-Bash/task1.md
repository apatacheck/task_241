#### 1. Что такое шебанг?
Шебанг (shebang) - это первая строка в скрипте, которая сообщает системе, какой интерпретатор нужно использовать для выполнения этого файла.

---
#### 2. Обязательно ли исполняемый файл должен иметь соотвествующее расширение?
Нет, не обязательно, главное, чтоб в файле был шебанг и чтоб у файла были установлены разрешения на выполнения.

---
#### 3. Напишите скрипт который выполнит автоматически действия из блока работы с файлами. ( не забудьте включить set -euo pipefail для того что бы ваш скрипт было удобнее отлаживать. Опишите что включают эти флаги)
**set -euo pipefail**: -e завершает выполнение скрипта, если любая команда завершилась с ошибкой, set -u   вызывает ошибку, если используется неинициализированная переменная, -o pipefail → если в цепочке команд одна из них завершается с ошибкой, скрипт тоже завершится.
**Создадим скрипт, выполняющий все задания из task1 (1-Work whith files):**
```
#!/bin/bash
set -euo pipefail

echo "1. Переместиться между директориями"
mkdir -p test
cd test
echo

echo "2. Вывести список файлов в директории"
ls
echo

echo "3. Вывести список Всех файлов в директории"
ls -la
echo

echo "4. Создать папку с подпапками"
mkdir -p folder1/testfolder1/testfolder2
echo "Созданы папки:"
find folder1
echo

echo "5. Внутри папки создать файлик и записать в него что-нибудь"
cat > folder1/testfolder1/testfolder2/info.txt <<EOF
что-нибудь
EOF #Этот флаг указывает на конец текста, который надо вписать в файл
cat folder1/testfolder1/testfolder2//info.txt
echo

echo "6. Переместить файл из одной директории в другую"
mkdir -p folder2
mv folder1/testfolder1/testfolder2/info.txt folder2/
echo "Файл перемещён в folder2:"
ls folder2
echo

echo "7. Скопировать файл из одной директории в другую"
cp folder2/info.txt folder1/
echo "Файл скопирован обратно в folder1:"
ls folder1
echo

echo "8. Переименовать файл"
mv folder1/info.txt folder1/renamed.txt
ls folder1
echo

echo "9. Сравнить содержимое файла"
echo "Добавим изменение в один файл для тестирования:"
echo "что-то новое" >> folder2/info.txt
diff folder1/renamed.txt folder2/info.txt || true
#true в этой строчке делает работу diff - корректной, без него, когда сравниваемые файлы будут разными, из-за флага -e, программа будет заканчиваться (т.к. это считается ошибкой)
echo

echo "10. Отсортировать содержимое файла по возрастанию и убыванию"
echo "По возрастанию:"
sort folder2/info.txt
echo
echo "По убыванию:"
sort -r folder2/info.txt
echo

echo "11. Удалить все папки и файлы"
cd ..
rm -rf test
echo "Все созданные папки и файлы удалены."
echo

```
Cохраним его в файл `task_bash.sh`, в консоли делаем этот файл исполняемым при помощи команды `chmod +x task_script.sh` (`chmod` = **change mode**, `+x` = добавить право на **выполнение**), и запускаем его:
