#### 2. Что такое общая папка, зачем оно может быть нужно?
Общая папка - это папка, доступ к которой можно предоставить нескольким пользователям или устройствам для совместной работы с файлами. Компьютеры, объединенные в одну сеть, могут получать доступ к общей папке. Пользователи могут просматривать, изменять или добавлять файлы, в зависимости от предоставленных прав доступа.

#### 3. Создайте общую папку без пароля с правами только на чтение файлов
Создаем рекурсивно папку `public_readonly` и устанавливаем на нее права только на чтение, кроме владельца, владелец будет иметь все права, (`755`). Для того чтобы изменить права только на чтение у ВСЕХ, в команде `chmod ` надо указать (`555`): 

![Настройка папки только чтение](images/Pasted%20image%2020251222184207.png)

Для настройки работы самой `Samba`, надо открыть `smb.conf` и прописать имя, путь, видимость папки в списке сетевых ресурсов и т.д.

![Конфиг Samba только чтение](images/Pasted%20image%2020251222184812.png)

Проверяем работу папки, заходим на неё. В эту папку я поместила файл `test_read.txt`, он содержит текст который можно прочитать. Для этого используется команда `get`, для копирования файла с Samba-сервера на мою виртуалку. После копирования файла его можно прочитать при помощи команды `cat`, префикс `!` нужен для выполнения локальных команд. Чтение работает.
Для проверки записи я создаю файл на своем компьютере при помощи команды `echo`, а потом копирую его на Samba-сервер. Это действие прерывается ошибкой, которая явно дает понять , что мы делаем что-то не так, а именно пытаемся записать файл туда, где запись файлов запрещена. 
Ну, и проверка удаления командой `rm` выведет связанную ошибку.

![Проверка папки только для чтения](images/Pasted%20image%2020260105200411.png)

Проверяем, что папка открывается с другого компьютера. Для этого я со своего компьютера (не с виртуалки) захожу в проводник, там ввожу IP своей виртуальной машины в формате `\\192.168.10.77` и нажимаю Enter.
Эта папка будет выглядеть таким образом:

![Папка в проводнике Windows](images/Pasted%20image%2020260107004535.png)

При заходе в папку` public_readonly`, мы видим уже созданный файл `test_read.txt` . Его можно прочитать, но при изменении будет вылетать ошибка доступа. При создании и удалении тоже будет вылетать ошибка:

#### 4. Создайте общую папку с паролем с правами на чтение и запись
Создаем  папку `secure_rw` и устанавливаем на нее права на чтение и запись только у владельца и группы (`770`).

![Создание защищенной папки](images/Pasted%20image%2020251222185539.png)

Классически создаем пользователя `smbuser`, после этого создаем пользователя в Samba и задаем пароль, который и будет использоваться для доступа к папке, команда:
`smbpasswd -a smbuser`
Прописываем в `smb.conf`:

![Конфиг Samba с паролем](images/Pasted%20image%2020251222185434.png)

Проверяем работу, пытаемся зайти на сервер без пароля `(1)`, с неправильным паролем `(2)`, или с неправильным пользователем `(3)` и наконец с правильным паролем (4). При первых трех случаях будет выводится ошибка. (Команды `smbclient` с флагом `-U` (`username`) нужны для указания имени пользователя и пароля. )

![Проверка защищенной папки](images/Pasted%20image%2020260105201800.png)

При запуске папки с другого компьютера работа авторизации будет выглядеть немного другим образом. При попытке открытия папки будет появляться окно авторизации:

![Окно авторизации Windows](images/Pasted%20image%2020260107005001.png)

После входа, пользователь может создавать/изменять и удалять файлы/папки и все остальное.

Доказательство того что я все это делаю совсем не зря, попробуем к этой папке подключиться. Сначала пробуем подключиться без пароля `(1)`, потом подключаемся пользователем, который не состоит в нужной группе `(2)`, и наконец используем нужного пользователя с нужным паролем `(3)`.
