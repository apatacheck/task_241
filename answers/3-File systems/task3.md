# Продолжаем

#### 1. Выведите содержимое fstab. Что хранится в fstab?
В файле fstab содержится информация о дисках, разделах и точках монтирования.
![Содержимое fstab](images/Pasted%20image%2020251110090525.png)

#### 2. Добавьте в виртуальную машину ещё один диск
С помощью Virtual Box создала диск linuxalt_2.
![Добавление диска](images/Pasted%20image%2020251110090604.png)

---
#### 3. Узнайте как сиcтема видит ваш диск - выведите информацию о блочных устройствах
Чтоб вывести информацию о дисках можно использовать команду `lsblk`:
![Информация о дисках](images/Pasted%20image%2020251110090752.png)

Новый диск отображается в таблице (`sdb`).

---
#### 4. С помощью полученной информации создайте на диске таблицу разделов и файловую систему ext4
Для начала я создаю таблицу разделов с помощью `fdisk`, настраиваю её:

![Создание разделов](images/Pasted%20image%2020251110091226.png)

После этого можно создать файловую систему при помощи команды  `mkfs` ext4 — тип файловой системы, /dev/sdb1— раздел на диске, где будет создана файловая система):

![Создание файловой системы](images/Pasted%20image%2020251110091356.png)

---

#### 5. Примонтируете диск в каталог /mnt
 Смонтировать диск можно при помощи команды `mount`. Далее при вызове команды `df -h` (команда показывает информацию о дисках) будет видно куда смонтирован наш диск:
  ![Монтирование диска](images/Pasted%20image%2020251110091702.png)
#### 6. Зайдите в каталог и создайте там файлы
При помощи `cd` перехожу в каталог `mnt` и создаю там файл test.txt. 
![Создание файла](images/Pasted%20image%2020251110091907.png)

---
#### 7. Отмонтируйте диск и проверьте остались ли файлы
Отмонтирую диск при помощи команды `umount`,  потом примонтирую его обратно при помощи команды `mount`, файл остался в целости. ``

![Отмонтирование диска](images/Pasted%20image%2020251110092049.png)
