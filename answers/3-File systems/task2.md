#### 1.Какая структура каталогов в linux? выведите список файлов в корне системы
В Linux используется древовидная структура каталогов, где корень `/` содержит все системные каталоги (/bin, /etc, /home, /var и т.д.), организованные по функциональному назначению.

#### 2. Где хранятся папки пользователей в системе?
Папки пользователей хранятся в каталоге `/home/`.

#### 5. Что за папки /bin,/sbin,usr/sbin,/usr/sbin
В Linux системные каталоги организованы по функциональному назначению. `/bin` содержит основные команды для всех пользователей, такие как `ls` и `cp`, необходимые для минимальной работы системы. `/sbin` хранит критически важные утилиты для администрирования, например `fdisk`, требующие прав root. `/usr/bin` включает большинство пользовательских приложений, установленных дополнительно, а `/usr/sbin` — дополнительные системные сервисы вроде `sshd`.

Каталог **/run** используется для хранения временных данных о состоянии системы и служб во время текущей работы. Он размещается в оперативной памяти, очищается при перезагрузке и содержит PID-файлы, сокеты и служебные данные системных процессов.
Каталог **/dev/shm** предназначен для разделяемой памяти и также находится в оперативной памяти. В нём хранятся объекты POSIX shared memory, используемые процессами для быстрого обмена данными, и все данные удаляются при перезагрузке системы.
